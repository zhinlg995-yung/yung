# 简记｜个人 iPhone 笔记 App（第一版）

这是一个可安装到 iPhone 主屏幕的 PWA（渐进式网页应用）。不需要 Mac，也不需要把应用提交到 App Store。项目是纯静态文件，部署到 HTTPS 网站后即可安装。

## 当前版本功能

- **自动保存**：输入后自动保存到本机 IndexedDB；不需要点击保存按钮。
- **文件夹分类**：新建、重命名、删除文件夹。删除文件夹时，其中的笔记会移动到“默认文件夹”，不会一起删除。
- **搜索**：搜索笔记标题、正文及待办事项内容；搜索范围受当前所选文件夹/待办筛选影响。
- **待办清单**：独立创建清单，添加事项、勾选完成、删除事项，并显示完成进度。
- **收藏笔记**：在编辑区点击星标，可将笔记置顶。
- **本地备份**：导出 JSON 备份；可在另一台设备或重新安装后导入。
- **离线打开**：首次联网打开并缓存成功后，可在已安装的主屏幕应用中离线使用核心功能。
- **响应式界面**：Windows 电脑浏览器和 iPhone 屏幕均可使用。

## 隐私与数据保存说明

1. 本项目不包含账号系统、分析代码或云同步代码，也不会把笔记内容发送到服务器。
2. 笔记保存在当前设备、当前网站来源的浏览器本地 IndexedDB 中。
3. 网站托管服务只提供 HTML、CSS、JavaScript、图标等应用文件；你的笔记内容不在网站仓库中。
4. **本地保存不等于永久备份。** 清除网站数据、浏览器数据、卸载/重置设备或存储空间异常，都可能导致笔记无法恢复。请定期使用“备份笔记”导出 JSON，并把备份放到电脑或其他安全位置。
5. 为保护隐私，请不要在公共电脑上录入私人笔记。任何能使用你已解锁 iPhone 的人，都可能打开这个应用查看内容；第一版没有应用密码/生物识别锁。

## 一、在 Windows 上发布网站（推荐 GitHub Pages）

PWA 需要 HTTPS 才能可靠使用 Service Worker 离线缓存。不要直接把 `index.html` 当作普通文件打开后尝试安装。

### 1. 解压项目

把下载的 `jianji-pwa.zip` 解压到 Windows 电脑。打开解压后的 `jianji-pwa` 文件夹，你应该能看到：

- `index.html`
- `styles.css`
- `app.js`
- `manifest.webmanifest`
- `sw.js`
- `icons` 文件夹

上传时要上传这些文件和 `icons` 文件夹里的内容，不要只上传 ZIP 文件。

### 2. 创建 GitHub 仓库

1. 在浏览器打开 `https://github.com/`，登录或注册账号。
2. 点击右上角 `+`，选择 `New repository`。
3. Repository name 可以填写 `jianji-notes`。
4. 为了使用 GitHub 免费 Pages，建议选择 `Public`。这只会让网页应用代码可见，不会公开你在 iPhone 中写的笔记；笔记数据只在你的设备本地。
5. 点击 `Create repository`。

### 3. 上传应用文件

1. 进入新建的仓库，点击 `Add file` → `Upload files`。
2. 把 `jianji-pwa` 文件夹内的**所有文件和文件夹**拖到上传区域（包括 `icons` 文件夹）。注意不要把外层文件夹再套一层，否则首页路径可能不正确。
3. 页面下方点击 `Commit changes`。

### 4. 打开 GitHub Pages

1. 进入仓库 `Settings` → 左侧 `Pages`。
2. 在 `Build and deployment` 下，`Source` 选择 `Deploy from a branch`。
3. `Branch` 选择 `main`，目录选择 `/(root)`，点击 `Save`。
4. 等待页面显示已发布的网站地址。地址格式通常是：
   `https://你的GitHub用户名.github.io/jianji-notes/`

首次发布可能需要一点时间。以后更新应用文件，再上传并提交，Pages 会自动重新发布。

## 二、在 iPhone 上安装

1. 用 iPhone 打开 **Safari**（不要使用微信、抖音等 App 内置浏览器）。
2. 在地址栏打开上一步生成的 HTTPS 网站地址。
3. 等首页完整显示后，点击 Safari 的“分享”按钮（方框向上箭头）。
4. 选择“添加到主屏幕”。如果出现“作为网页 App 打开 / Open as Web App”开关，请打开。
5. 点击“添加”。主屏幕会出现“简记”图标。
6. 以后直接点击主屏幕图标使用。第一次使用请保持联网，等应用加载完成、显示“已保存在此设备”后再测试离线打开。

不同 iOS 版本的分享菜单名称/位置可能略有不同。

## 三、日常使用

- **新建笔记**：点击“新建笔记”。
- **新建待办**：点击“新建清单”，输入事项并回车或点击“添加”。
- **整理文件夹**：左侧导航中的 `＋` 创建文件夹；文件夹右侧的 `···` 可重命名或删除。
- **移动笔记**：打开笔记，在编辑区顶部的文件夹下拉菜单中选择目标文件夹。
- **搜索**：在搜索框输入关键词。
- **收藏**：打开笔记，点击右上角星标。
- **备份**：电脑宽屏界面左下角选择“备份笔记”；iPhone 窄屏界面点击右上角的备份图标。将下载的 JSON 文件另存到“文件”或电脑。
- **恢复**：选择“导入备份”，挑选之前导出的 JSON 文件。导入会替换当前设备上的全部笔记，操作前请先备份当前内容。

## 四、常见问题

**为什么不能直接从 ZIP 安装？**

iPhone 主屏幕网页 App 需要一个 HTTPS 网站地址。ZIP 是源文件包，不是 iOS 安装包（IPA）。

**换手机后笔记会自动出现吗？**

不会。第一版没有云同步。请先导出 JSON 备份，再在新设备上打开应用并导入备份。

**离线时可以使用吗？**

首次在线访问并完成缓存后，应用外壳和主要功能可离线使用。首次加载、首次安装、清理缓存后重新打开都需要网络。

**我清除了 Safari 历史记录会丢笔记吗？**

是否删除网站数据取决于你选择的清理范围和 iOS 版本。不要清除该网站的数据；重要内容请定期导出 JSON 备份。不要把浏览器本地存储作为唯一备份。

**为什么在电脑上打开正常，iPhone 添加主屏幕却没有出现？**

确认你使用 Safari、网址为 HTTPS、网站首页能完整加载；然后重新打开分享菜单，找到“添加到主屏幕”。

## 添加图片和文件（1.1.0 新增）

1. 打开一篇笔记或待办清单，在标题下方点「🖼 图片」或「📎 文件」。
2. iPhone 点「图片」后，可选择“照片图库”“拍照或录像”；可以一次选多张。点「文件」可以从“文件”App 选择任意类型的文件。
3. 图片显示为缩略图，点一下查看大图（右上角「保存」可存到手机，× 关闭）；右上角的 × 删除图片。
4. 文件显示在列表里，点文件名打开或下载；「分享」可以存到“文件”App 或发给别人；「删除」移除文件。
5. 删除整篇笔记时，其中的图片和文件会一起删除。

**注意事项**

- 大图片会自动缩小到最长边 1600 像素，以节省空间；其他文件保持原样，单个文件不能超过 50 MB。
- 图片和文件同样只保存在这台 iPhone 的 Safari 本地存储里，空间受 iOS 限制（通常为几百 MB 到数 GB，设备剩余空间少时会更少）。放太多大文件可能导致保存失败，请适度使用。
- 「备份笔记」会把图片和文件一起打包进 JSON，所以备份文件会变大；附件很多时，导出可能因为内存不足失败，建议经常备份、分批整理。旧版备份仍可导入（但里面没有附件）。
- 更新到新版：联网状态下，关闭简记后重新打开一两次即可；笔记不会丢失。

## 本地预览（可选）

Windows 安装 Python 后，在项目文件夹地址栏输入 `cmd` 回车，再运行：

```bash
python -m http.server 8000
```

电脑浏览器访问 `http://localhost:8000/`。此方式只用于本机预览；不能直接用这个 localhost 地址在 iPhone 上安装。正式安装仍需 HTTPS 网站。
