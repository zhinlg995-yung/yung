# 更新记录

## 1.2.1
- 修复：删除笔记在部分 iPhone 主屏幕模式下仍然无效。确认框改为自绘浮层（不再依赖 `<dialog showModal>` / `returnValue`）。
- 修复：确认框 CSS 曾被截断导致弹层跑出屏幕外，现已修正（请更新到缓存 v6）。
- 编辑页增加醒目的「删除这篇笔记」按钮；右上角删除入口改为可见的「删除」文字。
- 删除成功后立刻写回 IndexedDB，并返回列表。

## 1.2.0
- 针对 iPhone 大屏（含 17 Pro Max）重做界面：更接近 iOS 原生 Notes 的简洁风格。
- 完整适配安全区（灵动岛/刘海、底部 Home 指示条），`viewport-fit=cover`。
- 加大字号、行高与触控区域（约 44pt）；减少边框、阴影和装饰色，用留白与字重区分层级。
- 列表、编辑区、待办、附件区和确认框一并简化；功能保持不变。

## 1.1.1
- 修复：iPhone 主屏幕模式下无法删除笔记、附件和文件夹（系统 `confirm` 对话框常被吞掉，已改为应用内确认框）。
- 修复：图片缩略图上的删除按钮可能被整块预览盖住，提高层级并拦截冒泡。
- 改进：待办事项删除按钮在手机上始终可见，并加大点击区域。

## 1.1.0
- 新增：笔记和待办清单里可以添加图片和文件（可多选）。iPhone 上点「图片」可从相册选择或直接拍照，点「文件」可从“文件”App 选择。
- 图片以缩略图显示，点开可查看大图；文件以列表显示名称和大小，点击可打开/下载，也可以分享或存到“文件”。图片和文件都可以单独删除。
- 大图片自动缩小（最长边 1600 像素）并压缩，节省手机存储；其他文件保持原样（单个文件不超过 50 MB）。
- 删除笔记时会同时删除它的附件；搜索可以匹配附件文件名。
- 备份与导入现在包含图片和文件（备份文件会变大）；旧版备份仍可正常导入。
- 数据库升级到第 2 版，原有笔记完整保留。
- 修复：打开笔记后，“给思绪一点空间”的空白提示仍显示在上方的问题。
- 更新机制：Service Worker 缓存升级为 v2，并在更新时绕过浏览器缓存，iPhone 重新打开即可拿到新版。

## 1.0.0
- 首个可运行版本。
- 笔记、文件夹、全文搜索、待办清单、收藏、JSON 备份与恢复。
- IndexedDB 本地持久化与 Service Worker 离线缓存。
